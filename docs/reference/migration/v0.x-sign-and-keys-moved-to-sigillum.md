# v0.x: `gtb sign` and `gtb keys` moved to sigillum

[sigillum spec 0007](https://gitlab.com/phpboyscout/sigillum/-/wikis/specs/0007-sigillum-is-the-signing-cli) makes [sigillum](https://sigillum.phpboyscout.uk) the estate's one signing CLI. This release takes the signing commands out of gtb (D6).

## What changed

- **`gtb sign` and `gtb keys` are gone.** `gtb keys generate`, `gtb keys mint`, `gtb keys wkd` and `gtb sign` now report an unknown command. sigillum has every one of them, with the same flags: `sigillum sign`, `sigillum keys generate`, `sigillum keys mint` and `sigillum keys wkd`.
- **gtb links no signing backend.** The `aws-kms` and `local` backends were linked only for those commands, so a gtb binary no longer carries go/signing-cli, go/signing-aws-kms or the AWS SDK through them.
- **gtb's own releases are signed by sigillum.** The release pipeline runs the sigillum binary from its CI image. The signature is the same armored detached OpenPGP signature over `checksums.txt`, from the same key.

## What did not change

- **Self-update.** A tool's updater verifies `checksums.txt.sig` exactly as before, so installed copies of gtb and of every generated tool update across this release.
- **Generated projects.** Their release pipelines already sign with `cmd: sigillum`. `gtb generate --signing-backend` and `gtb enable signing --backend` still take `aws-kms` or `local`, now checked against the backends sigillum links rather than gtb's own.

## Moving a script or pipeline

1. Install sigillum, either with `go install gitlab.com/phpboyscout/sigillum/cmd/sigillum@latest` or from a binary on its [releases page](https://gitlab.com/phpboyscout/sigillum/-/releases). The phpboyscout `go-tools` CI image already carries it.
2. Replace `gtb` with `sigillum` in the command and keep every flag:

    ```bash
    # before
    gtb --ci sign --backend aws-kms --kms-region eu-west-2 \
        --key-id alias/release-signing --public-key release.asc \
        --output checksums.txt.sig checksums.txt

    # after
    sigillum --ci sign --backend aws-kms --kms-region eu-west-2 \
        --key-id alias/release-signing --public-key release.asc \
        --output checksums.txt.sig checksums.txt
    ```

3. A `go run ./cli/cmd/gtb ... sign` line, as gtb's own release script had, becomes a plain `sigillum` call. Nothing has to be built at release time.
