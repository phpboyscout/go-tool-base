# v0.x: `chat.ProviderNames` removed

`chat.ProviderNames()` returned every provider the chat adapter's module table knows, comma separated, for help text.
That is the wrong list for help text: a binary registers only the providers its `main` blank-imports, so the list named
providers the binary could not use. `docs ask --provider` now lists the providers the binary links, and nothing else
called the function.

## What to change

- **For every provider the adapter knows**, read `chat.ProviderModules()` and take each entry's `Provider`.
- **For the providers this binary links**, which is what help text wants, call
  `chat.LinkedProviders(p.GetFeatures())`. `docs ask` builds its `--provider` help from it.
