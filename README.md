# Go Tool Base (GTB) — moved

**This repository has moved to GitLab.**

All ongoing development, issues, releases, and documentation live at:

**https://gitlab.com/phpboyscout/go-tool-base**

This GitHub mirror is now archived and read-only. Open issues, pull requests, and discussions here will not be answered — please raise them on GitLab.

## What changed

- **Module path:** `gitlab.com/phpboyscout/go-tool-base` (was `github.com/phpboyscout/go-tool-base`).
- **Versioning reset:** the GitLab side starts at `v0.1.0`; prior tags on this GitHub repo (v1.x and v2.0.0) are no longer authoritative.
- **Installation:** `go install gitlab.com/phpboyscout/go-tool-base/cmd/gtb@latest` or via the install script at `https://gitlab.com/phpboyscout/go-tool-base/-/raw/main/install.sh`.
- **Homebrew:** `brew tap phpboyscout/homebrew https://gitlab.com/phpboyscout/homebrew.git && brew install --cask gtb`.
- **Docs:** https://gtb.phpboyscout.uk.

The migration rationale and operational details live in the GitLab repo's `docs/development/gitlab-migration-followups.md`.
